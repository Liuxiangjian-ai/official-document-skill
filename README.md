 > **让 AI 写出的公文，读起来像是人写的。**
> 
> 这背后是什么？ 我们用 Codex 对数百篇《人民日报》《光明日报》等报刊文章做了系统分析——从用词频率、句式结构、段落推进方式，到语气控制、事实密度、文种差异——把其中的表达规律总结成了一套可复用的规则。它不是简单地模仿某一篇文章的文风，而是提炼出"好的机关材料长什么样"的底层逻辑。

> 不堆套话，不写空话，不把所有材料写得空洞无物。  
> 它会根据文种、场景和材料，生成结构规范、表达稳妥、内容具体、去 AI 味的中文公文。

## 你有没有遇到过这种情况？

让AI 帮你写一份工作报告，它给了你一段这样的文字：

```text
为深入贯彻落实高质量发展要求，进一步凝心聚力、开拓创新、真抓实干，
我单位持续强化责任担当，不断完善工作机制，全面推动各项工作走深走实、
提质增效，为谱写新时代事业发展新篇章贡献更大力量。
```

看起来辞藻华丽、对仗工整。但仔细一看——

> 谁在做事？做了什么？怎么做？什么时候做完？通通没有。

这就是典型的 **"AI 味"**：把一堆抽象词排列组合，听起来什么都说了，实际上什么都没说。

**这个 Skill 就是来解决这个问题的。**

---

## 它能做什么？

简单说：**把"AI 腔"改成"人话"——机关里真正能用的那种。**

同样一段意思，Skill 会改成：

```text
下一步，我单位将围绕任务分解、过程调度和结果反馈三个环节完善工作机制，
明确责任科室和完成时限，定期跟踪重点任务进展，推动相关工作按节点落实。
```

区别在哪？

| 典型 AI 味 | 去 AI 味后 |
|---|---|
| 凝心聚力、开拓创新 | 任务分解、过程调度、结果反馈 |
| 强化责任担当 | 明确责任科室和完成时限 |
| 走深走实、提质增效 | 定期跟踪重点任务进展 |
| 谱写新篇章 | 按节点落实 |

> 核心原则只有一条：**能看到"谁在做什么、怎么做、做到哪一步"的文字，才是能用的文字。**

| 改写动作 | 为什么这样改 |
|---|---|
| 删掉"提高政治站位"整段 | 说了等于没说——没有具体行动信息 |
| 每个整改事项列数字、对象、状态 | 事实才是公文的骨肉 |
| 如实写上"房东配合度不高" | 困难不隐瞒，这是真实工作信息 |
| 下一步全部是可执行动作 | 台账、跟踪、销号、上报——每一条都能落实 |
| 不写"为全区高质量发展贡献力量" | 结尾停在具体安排上，不拔高 |

## 四项核心能力

### 1. 文种识别 —— 先搞清楚要写什么

不是所有公文都一个写法。Skill 会先判断文种，再匹配结构。

| 文种 | 结构重点 |
|---|---|
| 通知 | 事项、对象、要求、时限 |
| 请示 | 理由、依据、请求事项 |
| 报告 | 情况、做法、问题、下一步 |
| 工作总结 | 完成情况、成效、不足、计划 |
| 工作方案 | 目标、任务、步骤、分工、保障 |
| 调研报告 | 现状、问题、原因、建议 |
| 领导讲话稿 | 形势判断、重点任务、落实要求 |
| 表态发言 | 思想认识、落实措施、责任承诺 |
| 简报 / 信息稿 | 导语、做法、成效、启示 |
| 宣传稿 | 场景、典型、做法、适度升华 |
| 理论评论文章 | 问题、观点、论证、收束 |

### 2.  去 AI 味 —— 主动扫描并压缩十类问题

- 空泛套话 · 机械排比 · 四字词堆叠 · 过度拔高 · 万能结尾
- 动词无宾语 · 宣传腔过重 · 理论腔过重 · 文种错位 · 缺少事实支撑

### 3.  事实密度增强 —— 公文的价值不在辞藻，在信息

Skill 会优先补足七个维度：

> **谁负责 → 做什么 → 针对什么问题 → 通过什么机制 → 到什么时间完成 → 如何跟踪 → 有哪些结果**

### 4.  语气克制 —— 到什么程度说什么话

| 表达强度 | 什么时候用 |
|---|---|
| 已启动、正在开展 | 只有部署或起步动作 |
| 有序推进、稳步推进 | 有计划有步骤，但结果有限 |
| 取得进展、初见成效 | 有阶段性结果或对象反馈 |
| 取得明显成效、形成机制 | 有数据、制度、流程或稳定运行 |
| 重大突破、历史性成就 | 有权威认定、关键指标或行业比较 |

## 内置评分 —— 写完了自动打分，不合格自动改

Skill 会从六个维度给生成的文本打分，分数不够就继续改，直到能用为止。

| 维度 | 分值 | 它在看什么 |
|---|---:|---|
| 事实密度 | 20 | 有对象吗？有动作吗？有机制吗？有数据吗？ |
| 文种适配 | 20 | 结构对吗？该有的部分都有吗？ |
| 语气克制 | 15 | 有没有没依据就拔高？ |
| 句式自然 | 15 | 是不是在机械排比？句式单一？ |
| 抽象词控制 | 15 | 套话密不密集？四字词有没有堆叠？ |
| 结构清晰 | 15 | 每段功能明确吗？推进自然吗？ |

**打分后的处理：**

| 分数 | 怎么办 |
|---|---|
| **≥ 90** |  直接输出，标注"已通过评分" |
| **80—89** |  定位被标记段落，压缩套话、补充信息 |
| **70—79** |  空转段落整段重写，保留已有事实 |
| **< 70** |  按文种结构整体重构，事实信息不丢 |

##  这些词，写的时候停一秒

不是不能用——但如果后面不接具体的东西，它们就是 AI 味的来源。

| 高风险表达 | 它的问题 | 怎么改 |
|---|---|---|
| 持续深化 | 深化了什么？ | 说出具体深化了哪项工作 |
| 扎实推进 | 怎么推进的？ | 说出步骤、节点、责任人 |
| 全面加强 | 加强了什么？ | 说出具体措施和程度 |
| 不断提升 | 提升了什么？ | 说出指标和变化 |
| 提质增效 | 质和效在哪？ | 给出数据或对比 |
| 走深走实 | 太空了 | 换成"落实到XX环节" |
| 落地见效 | 怎么见效？ | 说出具体表现 |
| 凝心聚力 | 宣传腔太重 | 换成"组织XX参与" |
| 开创新局面 / 谱写新篇章 | 过度拔高 | 直接删，或换成下阶段目标 |
| 提高政治站位 | 空转惯用开头 | 删掉；必须保留则后面接行动 |
| 强化责任担当 | 谁担什么责？ | 说出具体责任和考核方式 |
| 坚持问题导向 / 目标导向 | 标签化表达 | 换成"针对XX问题""围绕XX目标" |

>  **判断标准：这个词删掉之后，句子还剩下有用的信息吗？如果什么都不剩——这个词就是在占位置。**

##  设计理念 —— 规则来自数据，不是直觉

这个 Skill 的每一条规则都不是凭空想的。

我们通过 Codex 对数百篇《人民日报》《光明日报》等报刊文章做了大规模分析——统计用词频率、拆解句式结构、追踪段落推进方式、量化不同文种的语气差异——然后把这些规律蒸馏成可复用的写作规则。

结果就是这个内核，四个字：

> **有事、有人、有数、有度。**

- **有事** —— 说了具体什么事？（而不是"贯彻落实""扎实推进"）
- **有人** —— 谁在做？谁负责？（而不是"形成工作合力"）
- **有数** —— 做到哪了？进度多少？（而不是"取得阶段性成效"）
- **有度** —— 语气跟事实匹配吗？（而不是一律"重大突破"）

公文不是越华丽越好。**能看出"谁在做什么、怎么做、做到哪一步、下一步怎么办"的材料，才是能用的材料。**

##  使用须知

- 本 Skill 不能替代真实业务审核；
- 涉及政策、法律、会议、人名、数据时，请以真实材料为准；
- 材料不足时，Skill 用稳妥占位，不凭空编造；
- 人民日报文章 ≠ 所有公文；蒸馏的是表达规则，不是复制文风；
- 去 AI 味不是随意化——目标是增强事实密度、文种适配和可执行性。
