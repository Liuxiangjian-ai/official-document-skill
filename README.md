> 一个面向中文公文写作的 ChatGPT Skill：  
> **不堆套话，不写空话，不把所有材料写成宣传稿。**  
> 它会根据文种、场景和材料，生成结构规范、表达稳妥、内容具体、去 AI 味的中文公文。

---

## ✨ 这个项目是什么？

这是一个专门用于**中文公文写作与去 AI 味**的 Skill。

它不是让 AI 写出更华丽、更宏大、更像宣传口号的文字，而是让 AI 写出更接近真实机关材料的文本：

- 看得出是什么文种；
- 看得出谁在做什么；
- 看得出问题在哪里；
- 看得出下一步怎么落实；
- 语气稳妥，不乱拔高；
- 结构清楚，不空转；
- 能复制，能改，能上手用。

---

## 🧩 它解决什么问题？

很多 AI 生成的公文有一种熟悉的"AI 味"：

```text
为深入贯彻落实高质量发展要求，进一步凝心聚力、开拓创新、真抓实干，
我单位持续强化责任担当，不断完善工作机制，全面推动各项工作走深走实、
提质增效，为谱写新时代事业发展新篇章贡献更大力量。
```

看起来很正式，但问题很明显：**没有具体对象、没有具体动作、没有责任分工、没有时限要求、没有真实工作信息。**

这个 Skill 会把它改成更可用的表达：

```text
下一步，我单位将围绕任务分解、过程调度和结果反馈三个环节完善工作机制，
明确责任科室和完成时限，定期跟踪重点任务进展，推动相关工作按节点落实。
```

## 🚀 核心能力

### 1. 文种识别

Skill 会先判断用户到底要写什么，而不是直接套一个万能模板。

| 文种 | 重点 |
|---|---|
| 通知 | 事项、对象、要求、时限 |
| 请示 | 理由、依据、请求事项 |
| 报告 | 情况、做法、问题、下一步 |
| 工作总结 | 完成情况、成效、不足、计划 |
| 工作方案 | 目标、任务、步骤、分工、保障 |
| 调研报告 | 现状、问题、原因、建议 |
| 领导讲话稿 | 形势判断、重点任务、落实要求 |
| 表态发言 | 思想认识、落实措施、责任承诺 |
| 简报 / 信息稿 | 导语、做法、成效、启示 |
| 宣传稿 | 场景、典型、做法、适度升华 |
| 理论评论文章 | 问题、观点、论证、收束 |

### 2. 去 AI 味

Skill 会主动检查并压缩以下问题：

- 空泛套话；
- 机械排比；
- 四字词堆叠；
- 过度拔高；
- 万能结尾；
- 动词无宾语；
- 宣传腔过重；
- 理论腔过重；
- 文种错位；
- 缺少事实支撑。

### 3. 事实密度增强

公文不是越"高级"越好，而是越能说明工作越好。Skill 会优先补足：

- 谁负责；
- 做什么；
- 针对什么问题；
- 通过什么机制；
- 到什么时间完成；
- 下一步如何跟踪；
- 有哪些阶段性结果。

### 4. 语气克制

没有证据，不乱用强判断。

| 表达强度 | 适用条件 |
|---|---|
| 已启动、正在开展 | 只有部署或起步动作 |
| 有序推进、稳步推进 | 有计划、有步骤，但结果有限 |
| 取得进展、初见成效 | 有阶段性结果或对象反馈 |
| 取得明显成效、形成机制 | 有数据、制度、流程或稳定运行结果 |
| 重大突破、历史性成就 | 有权威认定、关键指标、行业比较或重大节点 |

## ✅ 内置评分逻辑

Skill 会对生成的文本按以下维度打分，并根据分数决定下一步处理：

| 维度 | 分值 | 关注重点 |
|---|---:|---|
| 事实密度 | 20 | 是否有对象、动作、机制、数据 |
| 文种适配 | 20 | 是否符合通知、请示、报告等文种结构 |
| 语气克制 | 15 | 是否存在无依据拔高 |
| 句式自然 | 15 | 是否机械排比、句式单一 |
| 抽象词控制 | 15 | 是否套话密集、四字词堆叠 |
| 结构清晰 | 15 | 段落功能是否明确、推进是否自然 |

处理规则：

| 分数 | 处理方式 | 具体动作 |
|---|---|---|
| **≥ 90** | 可直接输出 | 标注"已通过评分"，不再修改 |
| **80—89** | 局部压缩 | 定位被标记的段落，压缩套话、补充具体信息 |
| **70—79** | 重写部分段落 | 对空转段落（无事实、无动作、无对象）整段重写，保留已有的事实信息 |
| **< 70** | 整体重构 | 按文种结构重新组织，确保每段有明确功能，所有事实信息不丢失 |

## ⚠️ 高风险表达

这些词不是绝对不能用，但必须审慎——**抽象词后面应当接具体对象、动作、流程、责任或结果。**

| 高风险表达 | 问题 | 替代方向 |
|---|---|---|
| 持续深化 | 没说深化什么 | 说明具体深化了哪项工作、怎么深化 |
| 扎实推进 | 没说怎么推进 | 说明推进的步骤、节点、责任人 |
| 全面加强 | 没说加强什么 | 说明加强了哪项措施、到什么程度 |
| 不断提升 | 没说提升什么 | 说明提升了哪个指标、从多少到多少 |
| 提质增效 | 没有指标 | 说明质量指标或效率数据 |
| 走深走实 | 空泛 | 换成"落实到XX环节""细化到XX层面" |
| 落地见效 | 没说怎么见效 | 说明见效的具体表现或验证方式 |
| 凝心聚力 | 宣传腔 | 换成"组织XX参与""协调XX配合" |
| 开创新局面 / 谱写新篇章 | 过度拔高 | 删除或换成下一阶段的具体目标 |
| 提高政治站位 | 空转开头 | 删除整句；如果确需保留，后面必须接具体行动 |
| 强化责任担当 | 没主语 | 说明谁承担什么责任、如何考核 |
| 坚持问题导向 / 目标导向 | 标签式 | 换成"针对XX问题""围绕XX目标"并接具体内容 |

> 原则：抽象词可以有，但后面必须接具体对象、动作、流程、责任或结果。

## 🧠 设计理念

真正的"去 AI 味"，不是把文字写得更口语，也不是故意变得不正式。

它的核心是：

> **有事实、有结构、有边界、有语气控制。**

公文不是越华丽越好，也不是越宏大越好。  
能看出"谁在做什么、怎么做、做到哪一步、下一步怎么办"的材料，才是真正能用的材料。

## 📌 注意事项

- 本 Skill 不能替代真实业务审核；
- 涉及政策依据、法律条款、会议名称、领导姓名、数据时，请以真实材料为准；
- 材料不足时，Skill 会使用稳妥占位，但不会凭空编造；
- 人民日报文章不等于所有公文；
- 本 Skill 蒸馏的是表达规则，不是复制文风；
- 去 AI 味不是随意化，而是增强事实密度、文种适配和可执行性。
